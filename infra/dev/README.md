# infra/dev — local development homeserver

Synapse (pinned `v1.165.0`) with native Matrix username/password login (D64) and native Simplified Sliding Sync, on
Postgres. No MAS until M5; Sygnal and Halo's pushkin arrive in M1 (ADR-0015). Local development only.

```bash
docker compose -f infra/dev/docker-compose.yml up -d      # first start generates config + secrets into a volume
infra/dev/smoke.sh                                        # versions advertise sliding sync, password login, sync answers
infra/dev/create-user.sh alice                            # prompts for a password (or set HALO_DEV_PASSWORD)
docker compose -f infra/dev/docker-compose.yml down       # stop; add -v to wipe the database and generated secrets
```

| Setting | Default | Change with |
|---|---|---|
| Server name | `halo.localhost` (fixed on first start) | `HALO_DEV_SERVER_NAME` before the first `up` |
| Listen address | `127.0.0.1:8008` | `HALO_DEV_BIND=0.0.0.0` to reach it from a device on your LAN; `HALO_DEV_PORT` |
| Push (optional) | off | `HALO_APNS_TEAM_ID=<team> infra/dev/sygnal-config.sh`, put your APNs key at `infra/dev/secrets/AuthKey_<KEYID>.p8` (gitignored), then `docker compose -f infra/dev/docker-compose.yml --profile push up -d --build` (Halo's pushkin from `infra/sygnal`, ADR-0015; `restart: unless-stopped`). Check `docker ps`: without the gateway no badge or widget changes while the app is closed |
| Synapse version | `v1.165.0` (SOURCES) | `SYNAPSE_VERSION` — bump only together with SOURCES |
| MAS (optional OIDC stack) | off | `docker compose -f infra/dev/docker-compose.mas.yml up -d --wait && infra/dev/smoke-mas.sh` (isolated `halo-dev-mas` stack: Synapse `127.0.0.1:8009`, MAS `v1.29.0` on `127.0.0.1:8080`; contract: `TEST_RUNNER_HALO_DEV_MAS_SYNAPSE_URL=http://127.0.0.1:8009 scripts/contract-test.sh oidcDiscovery`) |

- Contract-test fixtures: `infra/dev/create-fixtures.py` creates the throwaway accounts and rooms the adapter contract tests need and
  writes `~/.config/halo-dev/contract.env` (mode 600; passwords are never printed). `--new-e2ee` makes a fresh account for the Encryption contract, which
  can set recovery up only once per account.
- Leftovers: the contract tests leave their rooms and sign out their devices also when they fail (`.cleansUp`), and `scripts/contract-test.sh` fails a
  run that left something. Only a run killed midway leaves any: `infra/dev/leftovers.py remove` lists them (exact test names, only the two accounts in the
  room; devices named "Halo (iPhone)" are never touched) and `remove --yes` removes them, which can't be undone.
- Secrets (registration shared secret, macaroon/form secrets, signing key) are generated by `synapse-init` into the
  `synapse-data` volume and never touch the repository. `synapse/homeserver.dev.yaml` holds only non-secret overrides.
- Postgres has no password and no published port; it's reachable only on the compose network.
- Rate limits are relaxed for scripted clients. Don't reuse this configuration for the personal server.
