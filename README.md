# Halo

An independent, proprietary Matrix client for iOS — built with SwiftUI on the official `matrix-rust-sdk`.

**Status:** Phase 0 (documentation) complete and approved (2026-11-19); implementation hasn't started — next is M0. See [docs/PHASE0_REPORT.md](docs/PHASE0_REPORT.md).

- **Start here:** [AGENTS.md](AGENTS.md) (engineering contract) → [HANDOFF.md](HANDOFF.md) (current state and next steps) → [docs/README.md](docs/README.md) (documentation index).
- **Why Halo:** unread badges that are always right, a Discord-style sticker experience on spec image packs, and native rendering of your own bots.
